# HTTP Server
Build a lightweight HTTP web server that can handle multiple client connections concurrently using POSIX threads. This project lets you dive into socket programming, threading, and basic HTTP protocol handling—all pure software, no hardware required.

Why It Rocks:

Real-world relevance: Web servers are at the heart of web services.

Concurrency: You’ll get hands-on experience with multi-threading.

Networking: Learn low-level socket programming.
